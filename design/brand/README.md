# Unred It brand (approved 2026-11-06, session 001)

## App icon (D-037)
- File: `icon.svg` (viewBox 100 x 100).
- Shape: drawn upside-down lowercase r. Stroke width 11, round caps and joins.
- Colors: stroke brick red `#E5736B`; tile Deep `#1A1A1A`; tile corner radius 24.
- The browser and store need PNG sizes (for example 16, 32, 48, 96, 128). Export them from `icon.svg` in milestone M1. Do not redraw the shape.

## Wordmark (D-036)
- Text: `unred it`, all lowercase, two words.
- Typeface: Inter Tight, weight 600 (semibold), letter-spacing -0.035em.
- Color: only "red" is red. Dark backgrounds: `#E5736B`, rest `#E6E6E6`. Light backgrounds: `#C2413A`, rest `#222222`.
- Lockup: icon to the left of the wordmark, icon height about 1.3 x the wordmark's cap height, gap about 0.4 x icon width.

## Do not
- Do not tint the backgrounds (D-031).
- Do not use the Reddit logo, the Reddit alien, or Reddit's orange.
- Do not set the icon as a font glyph; use the drawn shape so it is the same in every browser.
