## Judgment calls
<Choices made without asking the owner, each with the reason, so the owner can overrule them; or "none".>
- Choosing a feed is a normal page load (allowed by the kickoff); the reader takes the new page over. The new page replaces the picker's history entry, so Back returns to the feed you came from.
- On desktop and tablet the sheet is a 400 px panel under the button, not the full width (the mock-up shows only the phone).
- On a touch screen, focus goes to the sheet, not the filter field, so the keyboard does not cover the list on open; with a mouse, the filter field gets focus.
- Followed user profiles (u/…) are left out of "Your subreddits": the reader cannot show a profile yet.
- Typing a valid name adds a "Go to r/<name>" row (the mock-up's placeholder says "Filter or go to r/…"); Enter opens the first row, which is shaded as the default.
- The current subreddit's row is shown in blue with aria-current (the spec only names the chip colors).
